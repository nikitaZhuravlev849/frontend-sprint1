# Научиться учиться

## Описание проекта

Одностраничный информационный сайт о современных техниках обучения. Страница рассказывает о методах эффективного усвоения знаний: методе Фейнмана, принципах Джоша Кауфмана, практиках Барбары Оакли, а также содержит подборку TED-видео и полезных ресурсов по теме.

### Функциональность

- Анимированный синий квадрат в шапке (непрерывное вращение)
- Анимированный треугольник в блоке Кауфмана (непрерывное вращение)
- Плавное изменение прозрачности всех ссылок при наведении
- Встроенные YouTube-видео через `<iframe>`
- Переиспользуемые БЭМ-блоки: `two-columns`, `table`, `section-title`, `section-subtitle`, `logo`, `rotation`

### Технологии

- **HTML5** — семантическая разметка (`header`, `main`, `footer`, `section`, `nav`, `blockquote`)
- **CSS3** — Flexbox, абсолютное позиционирование, CSS-анимации (`@keyframes`), свойство `transition`
- **БЭМ (Nested)** — методология именования классов и файловая структура `blocks/`
- **normalize.css** — сброс стилей браузера

## Планы по доработке

- Добавить адаптивную вёрстку для планшетов (breakpoint 768px) и мобильных устройств (breakpoint 480px) с помощью медиазапросов, чтобы страница корректно отображалась на всех экранах
- Подключить шрифт Inter через Google Fonts вместо системного Helvetica Neue, чтобы улучшить типографику на платформах без этого шрифта
- Проверить и добавить вендорные префиксы (`-webkit-`, `-moz-`) для свойства `animation` и `transform` с помощью Autoprefixer, чтобы обеспечить корректное отображение в старых браузерах
